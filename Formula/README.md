# The Homebrew formula has moved

The formula lives in its own tap, [`parsabee/homebrew-paykanlang`](https://github.com/parsabee/homebrew-paykanlang):

```sh
brew install parsabee/paykanlang/paykanlang
```

If you tapped this repository before (`brew tap parsabee/paykanlang https://github.com/parsabee/PaykanLang`),
point the tap at the new repository once:

```sh
brew tap --custom-remote parsabee/paykanlang https://github.com/parsabee/homebrew-paykanlang
brew upgrade paykanlang
```

This directory is removed after the 0.2.0 release.
